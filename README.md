# Proyek 1B – Silsilah Organisasi

## Deskripsi
Proyek ini merupakan implementasi struktur data **General Tree** menggunakan bahasa pemrograman Python dengan konsep **Object-Oriented Programming (OOP)**. Program dibuat untuk menggambarkan struktur hierarki organisasi di lingkungan UIN Sultan Syarif Kasim Riau, mulai dari Rektor, Wakil Rektor, Dekan, Ketua Program Studi, hingga Dosen dan Staf.

## Fitur Program
- **Insert Node:** Menambahkan anggota organisasi ke dalam struktur pohon berdasarkan nama atasannya.
- **Search Node:** Mencari anggota organisasi berdasarkan nama atau jabatan.
- **Preorder Traversal:** Menampilkan data mulai dari root, kemudian anak-anaknya.
- **Inorder Traversal:** Menampilkan data dengan urutan anak pertama, node utama, kemudian anak-anak berikutnya.
- **Postorder Traversal:** Menampilkan data anak-anak terlebih dahulu, kemudian node utama.

## Teknologi
- Bahasa Pemrograman: Python
- Konsep Pemrograman: Object-Oriented Programming (OOP)
- Struktur Data: General Tree

## Tujuan
Menerapkan konsep struktur data Tree dalam menggambarkan hierarki organisasi serta memahami operasi penambahan, pencarian, dan traversal pada struktur pohon.
